# Author

## Assylkhan Yeraliyev

Software author, product designer, and lead full-stack developer of StudyMate LMS.

Assylkhan independently developed StudyMate over approximately 12–14 months as a personal project. His work included product planning, interface development with React and Redux, API and data modelling with Django REST Framework, authentication, academic workflows, testing, and deployment preparation.
