## Resume version

**StudyMate LMS — Independent Full-Stack Developer**  
Designed and developed a school learning management platform over 12–14 months using React, Redux Toolkit, Django REST Framework, and PostgreSQL. Implemented JWT authentication and role-based workflows for courses, assignments, grading, schedules, groups, announcements, awards, communities, and personal tasks. Deployed the frontend, API, and database on Render and protected the public portfolio account with server-side read-only controls.

## Interview talking points

- I built the project to understand how a single platform could support both academic administration and everyday learning.
- The main technical challenge was coordinating many related resources—users, courses, groups, assignments, marks, terms, and timetables—without breaking role-specific access.
- I separated the product into a React/Redux client and a Django REST API, with JWT authentication between them.
- Preparing it for public review taught me that deployment and security are part of software engineering, not just final presentation steps.
- If I continued the project, I would add automated end-to-end tests, accessibility improvements, audit logging, and a dedicated non-destructive demo dataset reset.
